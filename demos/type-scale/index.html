Typography System

Type on a good page is engineered, not chosen. One ratio generates every size; one baseline generates every gap; the measure is a constraint, not an accident. Drag the controls — every specimen below reads from the same custom properties.

1 · The scale

Each step is the previous multiplied by the ratio. A single number decides every size on the page, which is why sizes chosen from a scale look related and sizes chosen by eye do not.

The clamp() column is the actual generated CSS. Copy any row. Because the middle term is a viewport-relative line, the size moves continuously — there is no jump at any width.

2 · Measure

Line length is the most under-used typographic control on the web. Below ~45 characters the eye returns too often; above ~75 it loses the line on the way back.

3 · Vertical rhythm

Spacing derived from the baseline rather than picked per element. Every margin here is a multiple of --baseline, so text lands on a shared grid even across headings.

Rhythm is spacing you can predict

This paragraph's line-height is exactly one baseline unit. The heading above occupies two. The gap between every block is one more. Nothing here is a hand-tuned margin.

The practical payoff is not mystical alignment — it is that you stop making a decision for every gap, and the page stops having eleven slightly different spacings that nobody chose on purpose.

4 · Wrapping

Two properties that cost nothing and fix the two ugliest defaults: lopsided headings and orphaned last words.

default

A heading long enough to wrap onto several lines

Body copy left to wrap however it lands, which will often strand a single short word alone on the final line of the paragraph.

balance + pretty

A heading long enough to wrap onto several lines

Body copy left to wrap however it lands, which will often strand a single short word alone on the final line of the paragraph.

text-wrap: balance evens out line lengths — use it on headings and short blocks only; it is capped at a handful of lines because the algorithm is expensive. text-wrap: pretty is the body-copy one: it prevents orphans and bad rags without equalising lines.

5 · Numerals

Two switches that separate typeset text from default text. Tabular figures share one advance width so columns align; old-style figures have ascenders and descenders and sit better inside running prose.

Typography is a system, not a set of choices

The difference between a page that looks designed and one that looks assembled is rarely the typeface. It is whether the sizes relate to each other, whether the line length is controlled, and whether the vertical spacing follows a rule.

Every one of those is a constraint you set once, at the top of the stylesheet, and then never think about again.
