CSS-Native Carousel

A carousel is fundamentally a scroll container. CSS Overflow 5 adds the missing controls and selected-state machinery, letting the browser own boundaries, keyboard behavior and scroll state.

Baseline fallback: every card remains a touch-, wheel-, and keyboard-scrollable snap list when generated controls are unavailable.

1 · Generated previous and next buttons

::scroll-button() creates real stateful controls. The browser disables them at either boundary and scrolls by a page; CSS anchor positioning places them over the rail.

2 · Markers know the current target

Each card generates a marker; :target-current styles the active one. The browser builds the focus group and updates it from the eventual snap target, even while motion is still settling.

3 · The snapped card styles itself

Each card is a scroll-state container. Its contents react through @container scroll-state(snapped: inline), so selection does not require an IntersectionObserver or scroll listener.
