TSL Node Materials

Three Shading Language — shaders written as chained JavaScript nodes rather than GLSL strings. The same source compiles to WGSL on WebGPU and GLSL on WebGL, so one material runs on both with no branching in your code.

What a node graph looks like

Instead of assigning a string of GLSL, you assign an expression tree to a specific slot on the material. Three.js compiles the graph into whatever the active backend speaks. 

import { MeshStandardNodeMaterial } from 'three/webgpu';
import { time, positionLocal, normalLocal, mx_noise_float,
         vec3, mix, uniform } from 'three/tsl';

const speed = uniform(0.6);                     // live-updatable from JS

const n = mx_noise_float(
  positionLocal.mul(4).add(time.mul(speed))     // sample a moving 3D noise field
);

const material = new MeshStandardNodeMaterial();

// Vertex stage: push each vertex along its normal by the noise value.
material.positionNode = positionLocal.add(normalLocal.mul(n).mul(0.3));

// Fragment stage: blend two colours by the same noise value.
material.colorNode     = mix(vec3(0.1, 0.3, 0.9), vec3(1.0, 0.4, 0.1), n);
material.roughnessNode = n.oneMinus().mul(0.8);
material.emissiveNode  = vec3(0.2, 0.5, 1.0).mul(n.pow(4));

Why bother

  • One source, two backends. No dual GLSL/WGSL maintenance, and no #ifdef soup.
  • You keep the PBR pipeline. A raw ShaderMaterial means reimplementing lighting, shadows, tone mapping and fog. A node material lets you replace exactly the one slot you care about and inherit the rest.
  • Uniforms are real objects. uniform(0.6) returns a node with a .value you set from JavaScript — no location lookups.
  • It composes. Nodes are values; you can factor a fragment of shading into a function with Fn() and reuse it across materials.

Gotcha: displacement breaks lighting

Moving vertices in positionNode does not update the normals, so a displaced surface lights as if it were still smooth. Either recompute normals from the noise gradient (three samples and two cross products) or accept the softer look — for organic blobs the flat-shaded result often reads better anyway.
