CSS 2026 Primitives

Four small additions that remove surprising amounts of glue code: responsive path commands, typed attributes, computed foreground contrast and sibling-aware choreography.

1 · Responsive shape()

Unlike SVG-like path() strings, shape commands accept percentages, custom properties and calculations. Resize the viewport or hover: every control point remains relative to the element.

2 · Attributes become typed values

The numbers live in semantic data-progress attributes. CSS parses them as numbers and angles, then uses them directly in calculations—no generated inline width declarations.

3 · Contrast selected from the actual colour

contrast-color() chooses black or white from the computed background. It removes token-pair bookkeeping, but it cannot rescue a problematic mid-tone—large palettes still need contrast audits.

One colour token.

The foreground follows the live background automatically.

4 · Choreography without hand-authored indexes

sibling-index() and sibling-count() expose structure to calculations. Reorder or insert an item and delays recalculate; no --i attributes or nth-child ladder.
