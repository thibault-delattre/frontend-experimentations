Command Palette

A command menu is fast only when its information architecture, scoring, and keyboard model are fast. This one uses a native dialog plus the combobox/listbox pattern.

1 · One shortcut, complete keyboard control

⌘ K / Ctrl K opens from anywhere. Arrow keys move an active descendant, Enter runs it, Escape closes it, and the text input keeps DOM focus so typing never stops.

2 · Fuzzy scoring with visible evidence

Exact prefix beats word prefix, which beats an ordered character match. Matching characters are highlighted, and results preserve stable order when scores tie.

3 · Groups, empty states, and execution feedback

Commands are grouped by intent rather than implementation. Empty search explains recovery; executing closes the palette and announces the action without navigating this research page.
