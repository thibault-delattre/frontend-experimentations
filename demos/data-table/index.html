Data Tables & Grids

Use a semantic table for readable tabular data. Reach for the ARIA grid interaction model only when cell-by-cell keyboard operation is genuinely part of the product.

1 · Sorting announces its direction

Header buttons change one aria-sort at a time. Sorting is stable, type-aware, and never turns static cells into dozens of unnecessary tab stops.

2 · Search and facets compose

Text search and status filters operate on one source array, the result count is announced, and the zero-state stays inside the table geometry instead of collapsing the interface.

3 · Spreadsheet navigation is opt-in complexity

Tab enters one cell; arrows move within the grid, Home/End move across a row, and Control+Home/End jump corners. This pattern is for application-like grids, not ordinary reports.
