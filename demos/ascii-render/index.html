ASCII Renderer

Downsample any source to a coarse luminance grid, then print each cell as the glyph whose ink coverage matches its brightness. Works on anything you can draw to a canvas — including your webcam. 


      
      

      

        
        
        
        

          
          
          
          
          
        

        

          
          
          
        

        

          
          
        

      

    


    

      
The three steps

      
    
        
  1. 
          Draw the source small. Not full size then averaged —
          just drawImage into a canvas that is already
          columns wide. The browser's own downscale filter does the
          box-averaging for you, in native code.
        
    2. 
        
  2. 
          Measure the cell aspect. A monospace cell is roughly
          0.5–0.6× as wide as it is tall, so the work canvas must be squashed
          vertically by that ratio or everything comes out stretched. This demo
          measures the real ratio from the rendered font rather than guessing.
        
    3. 
        
  3. 
          Map luminance to a glyph. Index into a ramp ordered
          by ink coverage. Everything else — contrast, gamma, inversion — is
          done on the luminance value before the lookup.
        
    4. 
      


      
const lum = 0.2126*r + 0.7152*g + 0.0722*b;   // Rec.709, not (r+g+b)/3
const v   = Math.pow(clamp((lum/255 - .5) * contrast + .5), 1/gamma);
out += ramp[Math.round(v * (ramp.length - 1))];


      
Details that matter

      
    
        
  • 
          Use Rec.709 luminance weights, not the mean of the
          channels. Green carries most of perceived brightness; a flat average
          makes reds and blues collapse into the same glyph.
        
    • 
        
  • 
          Building the output with a single string and one
          textContent write per frame is dramatically faster than
          per-cell DOM. The coloured mode has to emit spans, which is why it
          costs roughly 10× more — group runs of equal colour if you need it
          faster.
        
    • 
        
  • 
          Set font-variant-ligatures: none. A programming font will
          otherwise fuse <= or :: into one glyph and
          shear the whole grid.
        
    • 
        
  • 
          Because the output is real text, it is selectable and copyable — the
          copy frame button just reads
          textContent.
