DEPTH

When to use which

  • Native CSS (see that demo) for reveals, progress bars and parallax. Zero bytes, runs off the main thread, cannot jank.
  • GSAP for anything that needs a real timeline: pinning, snapping, sequencing with overlaps, reversing at a different speed, or motion driven by something other than scroll position.
  • Always call ScrollTrigger.refresh() after fonts load or layout changes — stale start/end positions are the number one ScrollTrigger bug.
  • Register plugins once: gsap.registerPlugin(ScrollTrigger). In a framework, wrap setup in gsap.context() and call ctx.revert() on unmount, or triggers leak across route changes.
