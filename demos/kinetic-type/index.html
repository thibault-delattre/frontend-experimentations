Kinetic Typography

Type as the primary visual, not a caption on one. Everything here rides on variable font axes — one file that interpolates continuously through weight, width and slant, so motion along an axis is as smooth as moving a slider.

01 · scroll drives the weight and width axes

VARIABLE

font-variation-settings inside @keyframes, with animation-timeline: view(). The glyphs thicken and narrow as the block crosses the viewport.

02 · per-character stagger, one custom property

KINETIC MOTION

JavaScript does one thing: wrap each character and set --i. The delay ramp is calc(var(--i) * 60ms) — no timeline library, no per-glyph animation objects.

03 · pointer proximity

HOVER ACROSS ME

Each glyph gets a normalised distance --d; weight, width and colour all read from that single number. Move the pointer slowly — this is the interaction behind most award-site navigations.

04 · marquee skewed by scroll velocity

Scroll fast. The track's skew is driven by scroll delta and eased back to zero — the cheapest possible "the page has weight" cue.

notes

  • Animating font-variation-settings triggers layout on every frame. It is fine on one headline; it is not fine on a paragraph. For long text, animate transform instead.
  • Splitting text into spans destroys it for screen readers — keep the original string in an aria-label and mark the spans aria-hidden. main.js does this.
  • Prefer the registered shorthands (font-weight, font-stretch) where they exist; they interpolate the same way and inherit properly.
