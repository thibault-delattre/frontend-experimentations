Springs & Layout

Motion (formerly Framer Motion) for physics-based animation. A spring has no duration — it has stiffness, damping and mass, and it settles when the physics say so. That is why an interrupted spring looks right and an interrupted ease does not.

    Choosing spring values

    • stiffness — how hard it pulls toward the target. Higher is snappier. 100 is soft, 400 is sharp.
    • damping — how much it resists motion. Below the critical value it overshoots and bounces; at or above it settles without overshoot. Critical damping is 2·√(stiffness·mass).
    • mass — inertia. Higher mass means slower to start and slower to stop; it is the knob for making something feel heavy.
    • For UI, start at { stiffness: 300, damping: 30, mass: 1 } and adjust damping first. Reach for bounce only on things that should feel playful — never on a menu the user is waiting on.
