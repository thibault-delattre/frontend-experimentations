Anchor Positioning

Tether a floating element to a trigger, size it from the trigger's box, and let the browser retry alternative placements when it would overflow — all in CSS. This is the feature that removes a positioning library from most projects.

1 · Tooltip that flips at the edge

Scroll inside the dashed box. The tooltip prefers to sit above; when there is no room it flips below via position-try-fallbacks: flip-block.

I keep myself in view. No scroll listener, no resize observer, no getBoundingClientRect.

2 · Menu sized from its trigger

width: anchor-size(width) makes the panel exactly as wide as the button it belongs to, at any breakpoint.

3 · A label that follows a moving anchor

Drag the dot. The callout re-anchors every frame with no JavaScript involved in the positioning, and swaps to the other side via a named @position-try block when it runs out of room.

Positioned entirely by anchor() — drag me to the right edge and watch the fallback fire.

Notes

  • Only works on position: absolute / fixed.
  • Combine with the Popover API (popovertarget) to get top-layer stacking, light-dismiss and focus management for free — no z-index war.
  • Animate open/close with @starting-style and transition-behavior: allow-discrete, since popovers toggle display.
  • Safari support is still partial as of 2026 — treat it as progressive enhancement, or keep a small JS fallback behind @supports not (anchor-name: --a).
