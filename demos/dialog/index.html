Dialogs & Drawers

One semantic primitive, three spatial patterns. Native <dialog> supplies top-layer stacking, modal focus containment, Escape, and focus restoration; CSS and a little gesture code supply the choreography.

1 · Modal with a real exit

The browser owns modality. @starting-style creates the entry frame; allow-discrete makes closing animatable instead of disappearing before opacity can run.

2 · Focus-safe side drawer

A drawer is still a dialog—not a fixed div with a heroic z-index. That distinction provides inert background content and restores focus to the opener.

3 · Drag-to-dismiss sheet

Drag the handle down. Release distance and velocity both count, so a short flick works while a slow accidental movement springs home.
