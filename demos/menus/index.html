Menus & Disclosure

Three patterns that look similar but have different semantics: an action menu, a navigation mega menu, and content disclosure. Choosing the right primitive is half the implementation.

1 · Action menu with roving focus

Only one item is in the Tab sequence. Arrow keys move, Home/End jump, typeahead finds by label, Escape returns focus, and the Popover API handles top-layer light-dismiss.

2 · Mega menu with safe-triangle intent

Move diagonally from a trigger toward the panel. A short grace corridor prevents the menu collapsing as the pointer crosses neighboring triggers—the classic “diagonal problem.”

3 · Implementation notes

The essential behavior stays visible here without another disclosure interaction hiding the explanation.

Choose the right primitive

Use menus for actions and ordinary links for navigation destinations.

Keep state unified

Pointer and keyboard interaction must update the same open and focused state.

Preserve escape routes

Escape, light-dismiss, and focus restoration are part of the component.
