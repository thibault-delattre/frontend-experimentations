Form UX & Validation

Good forms preserve context, wait for user intent, expose native semantics and make every recovery path obvious. The visual layer follows that behavior.

1 · Fields grow from their own content

field-sizing: content replaces resize scripts for inputs and textareas. Minimums preserve the empty affordance; maximums introduce internal scrolling before the composer takes over the page.

CSSAccessibility

2 · Validation waits until it can help

CSS uses :user-invalid, not :invalid, so untouched required fields are neutral. Native constraints remain the source of truth; custom messages mirror them in linked, stable error slots.

3 · Drop zone backed by a real file input

Drag is an enhancement. The visible label activates the native picker, accepted types are enforced again in code, chosen files are announced, and each can be removed without reopening the dialog.
