04 · the honest part

Smooth scroll is a trade

  • It breaks native behaviour. Find-in-page, anchor jumps, scroll restoration, focus scrolling and the scrollbar thumb all have to be re-plumbed through the library.
  • Some people hate it, and some get motion sick. Respect prefers-reduced-motion and switch the whole thing off — this demo does.
  • It cannot use scroll-driven CSS animations. Native animation-timeline reads the real scroll offset, which is no longer where the content appears to be. Pick one or the other per project.
  • One rAF loop. Never call lenis.raf() from a second loop, and never read layout inside the scroll callback — cache your measurements and refresh on resize.
  • The alternative worth considering is nothing at all. Native scrolling is already smooth on every current platform; the case for Lenis is the eased virtual position other effects can read, not the smoothness itself.
