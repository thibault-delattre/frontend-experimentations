View Transitions

One API call — document.startViewTransition() — and the browser tweens between two DOM states. Elements that share a view-transition-name across the two states are morphed into each other; everything else cross-fades.

Click a card, then click the back button inside the detail.

Reordering a list

Give every row a unique name (--vt-name-3, derived from a stable id — never the array index) and the browser FLIPs them for you when the sort changes.

    Cross-document transitions

    The same effect works between two real navigations in a plain multi-page site. Put this in the CSS of both pages — no JavaScript, no router, no framework: 

    @view-transition { navigation: auto; }

    Then give the shared element the same view-transition-name on both pages. Same-origin only. Listen for pageswap / pagereveal to set names dynamically based on which link was clicked.
